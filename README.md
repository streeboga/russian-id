# streeboga/russian-id

Валидаторы контрольных сумм российских идентификаторов. Чистый PHP, ноль
runtime-зависимостей, strict typing. Алгоритмы сверены с `anper/russian-id`
(MIT) и официальными спецификациями.

| Класс | Идентификатор | Алгоритм |
|---|---|---|
| `Inn` | ИНН 10 (юрлица) / 12 (физлица, ИП) | взвешенная сумма mod 11 mod 10 (одна/две контрольные) |
| `Snils` | СНИЛС (11 цифр) | сумма с весами 9..1, mod 101 (100 → 0) |
| `Oms` | Полис ОМС, ЕНП (16 цифр) | Luhn |
| `Ogrn` | ОГРН (13) / ОГРНИП (15) | тело mod 11 (или mod 13) mod 10 |

## Использование

```php
use Streeboga\RussianId\{Inn, Snils, Oms, Ogrn};

Inn::isValid('7707083893');      // true
Inn::isValid('ИНН 7707 083893'); // true — вход нормализуется (выбрасывается всё, кроме цифр)
Snils::isValid('112-233-445 95'); // true
Oms::isValid('1234 5678 9012 3452'); // true
Ogrn::isValid('1027700132195'); // true (ОГРН), 15 цифр — ОГРНИП
```

Вырожденные последовательности (`00000000000` и т.п.) отклоняются, даже если
формально проходят контрольную сумму.

Основной потребитель в Rosary — `App\Services\Governance\SensitiveDataDetector`:
regex находит числового кандидата в тексте, контрольная сумма отсекает
случайные числа (та же схема, что card + Luhn).
